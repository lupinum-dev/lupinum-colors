# Writing public interface text

Use Lupinum Controlled English, based on ASD-STE100. Do not claim formal
certification.

- Use active voice and short sentences.
- Put one instruction in each sentence.
- Use specific labels that describe the result.
- Explain errors and the next action.
- Define technical terms when users need them.
- Use plain German for German text.
- Use “Tailwind CSS” for the product and “Tailwind” only when the shorter form
  remains clear.
- Do not imply affiliation with or endorsement by Tailwind Labs.

Review text in the real interface and at mobile width.
