## Tailwind CSS

The generator is calibrated from the color definitions distributed with
[Tailwind CSS](https://tailwindcss.com/). The committed reference records the
Tailwind version and a SHA-256 digest of the source data. Tailwind CSS is
available under the MIT License and is copyright Tailwind Labs, Inc.

“Tailwind CSS” and “Tailwind” are used only to describe compatibility and the
source of the reference color data.
